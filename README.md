# Creating My Alexa Skill with TTS and SSML Modifiers

## Overview

The Alexa Skill allows users to interact with TTS by asking Alexa to:

- Speak text loudly, softly, quickly, or slowly.
- Whisper the provided text.
- Handle unsupported inputs gracefully.
- Provide friendly help instructions and exit commands.

## Features

- **Customizable TTS**:
  - Volume: Alexa can speak loudly or softly.
  - Speed: Alexa can speak quickly or slowly.
  - Whispering: Alexa can whisper text.
- **Error Handling**: Friendly responses for unsupported or invalid inputs.
- **Built-in Intents**:
  - Help Intent: Provides instructions on using the skill.
  - Cancel/Stop Intent: Ends the session.

## Prerequisites

To create and test this skill, you will need:

- An Amazon Developer Account to access the Alexa Skills Kit.
- Basic knowledge of Alexa Skills creation and testing.
- Python 3.x installed locally (if running or testing outside the developer console).
